# Система онлайн чата для игры

## Описание системы

Реализована полноценная система онлайн чата для игроков с использованием HTTP протокола и серверной части на Flask.

## Компоненты системы

### Серверная часть (Python Flask)

1. **chat_endpoints.py** - API endpoints для работы с чатом:
   - `GET /api-game-chat/` - получение сообщений чата
   - `POST /api-game-chat/` - отправка сообщения
   - `POST /api-game-chat/system` - отправка системного сообщения
   - `GET /api-game-chat/online_count` - получение количества игроков онлайн

2. **database.py** - добавлена таблица `chat_messages` для хранения сообщений

3. **_GAME_SERVER_MAIN.py** - зарегистрирован новый blueprint для чата

### Клиентская часть (Unity C#)

1. **GameHTTPClient.cs** - HTTP клиент для взаимодействия с сервером:
   - Автоматическая регистрация/авторизация игроков
   - Отправка и получение сообщений чата
   - Управление состоянием подключения
   - Сохранение данных в PlayerPrefs

2. **GlobalChat.cs** - UI контроллер чата:
   - Отображение сообщений с выравниванием (свои справа, чужие слева)
   - Показ/скрытие чата по кнопке
   - Изменение цвета кнопки (красный = не подключен, зеленый = подключен)
   - Автоскролл к новым сообщениям
   - Счетчик игроков онлайн

3. **ChatScrollViewSetup.cs** - настройка ScrollView для чата

## Настройка в Unity

### 1. Настройка GameHTTPClient

1. Создай пустой GameObject и добавь компонент `GameHTTPClient`
2. Настрой `serverURL` (по умолчанию `http://127.0.0.1:3329`)
3. Этот объект будет автоматически сохранен между сценами (DontDestroyOnLoad)

### 2. Настройка GlobalChat

1. Добавь компонент `GlobalChat` к UI объекту
2. Настрой следующие поля в инспекторе:

**UI Elements:**
- `onlineCountText` - текст для отображения количества игроков онлайн
- `messagesContent` - RectTransform контейнера для сообщений (ScrollView/Viewport/Content)
- `inputField` - поле ввода сообщений
- `sendButton` - кнопка отправки сообщений
- `messagePrefab` - префаб для отображения одного сообщения (GameObject с TMP_Text)
- `chatCanvasGroup` - CanvasGroup всего чата для показа/скрытия
- `chatToggleButton` - кнопка для открытия/закрытия чата
- `chatToggleButtonImage` - Image компонент кнопки для смены цвета
- `scrollRect` - ScrollRect компонент для автоскролла

**Colors:**
- `connectedColor` - цвет кнопки при подключении (зеленый)
- `disconnectedColor` - цвет кнопки при отключении (красный)
- `ownMessageColor` - цвет своих сообщений
- `otherMessageColor` - цвет чужих сообщений
- `systemMessageColor` - цвет системных сообщений

### 3. Структура UI

```
ChatUI (CanvasGroup)
├── ToggleButton (Button + Image)
├── ChatPanel
│   ├── OnlineCountText (TMP_Text)
│   ├── MessagesScrollView (ScrollRect)
│   │   └── Viewport
│   │       └── Content (RectTransform + VerticalLayoutGroup + ContentSizeFitter)
│   └── InputPanel
│       ├── InputField (TMP_InputField)
│       └── SendButton (Button)
└── MessagePrefab (GameObject с TMP_Text)
```

## Функциональность

### Автоматическая регистрация/авторизация

При запуске игры система:
1. Проверяет PlayerPrefs на наличие ключа `isRegistered`
2. Если пользователь не зарегистрирован - создает случайные данные и регистрирует
3. Если зарегистрирован - авторизуется с сохраненными данными
4. Добавляет пользователя в лобби
5. Отправляет системное сообщение о подключении

### Работа чата

1. **Скрытие/показ чата**: Чат скрыт на старте (alpha = 0), показывается по клику на кнопку
2. **Цвет кнопки**: Красный = не подключен, зеленый = подключен
3. **Выравнивание сообщений**: Свои сообщения справа, чужие слева, системные по центру
4. **Автообновление**: Каждые 2 секунды обновляется счетчик онлайн и загружаются новые сообщения
5. **Отправка сообщений**: По кнопке Send или Enter в поле ввода

### Системные сообщения

Автоматически отправляются при:
- Подключении игрока к чату
- Отключении игрока от чата

## API сервера

### Регистрация пользователя
```
POST /api-game-user/register
{
    "email": "player@game.local",
    "password": "password123",
    "nick_name": "PlayerName"
}
```

### Авторизация
```
POST /api-game-user/login
{
    "email": "player@game.local", 
    "password": "password123"
}
```

### Отправка сообщения
```
POST /api-game-chat/
{
    "user_id": "user_1",
    "message": "Привет всем!"
}
```

### Получение сообщений
```
GET /api-game-chat/?limit=50&offset=0
```

### Получение количества онлайн
```
GET /api-game-chat/online_count
```

## Запуск сервера

```bash
cd Game/Assets/PythonServer
python _GAME_SERVER_MAIN.py
```

Сервер будет доступен по адресу: `http://127.0.0.1:3329`

## Тестирование

1. Запусти сервер
2. Запусти два инстанса Unity редактора 
3. В каждом инстансе должен автоматически создаться и авторизоваться пользователь
4. Кнопка чата должна стать зеленой
5. Попробуй отправить сообщения - они должны появляться в обоих инстансах

## Особенности для WebGL

Система использует UnityWebRequest, который работает в WebGL через браузерные HTTP запросы. Убедись что:
1. Сервер настроен с CORS заголовками (уже настроено)
2. При деплое на HTTPS сервер тоже должен быть HTTPS
3. В WebGL нет поддержки многопоточности, все запросы асинхронные через корутины
